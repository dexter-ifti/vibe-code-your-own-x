# Vibe Code Your Own X

> A modern, build-first map of the things worth building at the edge of software.

`Build Your Own X` made systems feel approachable by turning a giant field into small, runnable projects. This project applies the same idea to the current wave of agentic AI, harness engineering, graph systems, generative interfaces, and AI-native products.

The goal is not to collect every AI demo. The goal is to help a curious builder answer:

> “What is the smallest real system I can build to understand this idea?”

## What makes this different

- **Build briefs, not bookmarks.** Every entry should explain the core concept, a smallest useful scope, and a path to stretch it.
- **Primitives before products.** Start with loops, tools, state, graphs, memory, permissions, and evaluation before cloning a full platform.
- **Frontier-aware, not hype-driven.** We track new patterns while keeping the projects runnable, inspectable, and useful.
- **Multiple levels of depth.** A project can be a weekend build, a serious systems project, or a research-grade capstone.
- **Evidence-linked.** Each idea points to source projects, papers, or discussions so readers can go deeper.

## Start here

1. Build a [minimal agent harness](catalog.md#1-minimal-agent-harness).
2. Add a [permission gate and crash-safe transcript](catalog.md#2-permissioned-coding-agent).
3. Turn the loop into a [state graph](catalog.md#7-state-graph-agent).
4. Add [evals and replay](catalog.md#13-agent-evaluation-lab).
5. Pick a capstone that matches your curiosity.

The current curated seed list is in [`catalog.md`](catalog.md). The research and editorial model behind it is in [`research.md`](research.md).

## Status

This is the first local foundation. The catalog is intentionally opinionated and incomplete. We will grow it through runnable implementations, community submissions, and periodic research passes.
